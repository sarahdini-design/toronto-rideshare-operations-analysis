# Calculated Tables and Columns

This file documents the calculated table and columns I created in Power BI for the Toronto Rideshare Operations Analysis.

These calculations were added to support date filtering, hourly demand analysis, and ward-level comparisons.

---

## DimDate

I created a separate date table covering the full **Q2 2026** analysis period.

The table provides one consistent calendar structure for both the trip and daily summary data.

```DAX
DimDate =
ADDCOLUMNS(
    CALENDAR(DATE(2026, 4, 1), DATE(2026, 6, 30)),
    "Year", YEAR([Date]),
    "Month Number", MONTH([Date]),
    "Month", FORMAT([Date], "MMM"),
    "Day Number", WEEKDAY([Date], 2),
    "Day Name", FORMAT([Date], "ddd"),
    "Day Type", IF(WEEKDAY([Date], 2) >= 6, "Weekend", "Weekday")
)
```

### Fields Created

| Field | Purpose |
|---|---|
| `Date` | Calendar date generated by `CALENDAR()` and used to connect the model tables. |
| `Year` | Calendar year. |
| `Month Number` | Numeric month value used to sort months correctly. |
| `Month` | Short month name used in the report slicer. |
| `Day Number` | Numeric weekday value, with Monday as 1 and Sunday as 7. |
| `Day Name` | Short day-of-week name used in the dashboard. |
| `Day Type` | Groups each date into `Weekday` or `Weekend`. |

## Pickup Hour

I created `Pickup Hour` from the original pickup timestamp so trip demand could be compared by hour of day.

```DAX
Pickup Hour =
HOUR(Trips_Q2_2026[pickup_hr])
```

- This column was used in the **Hourly Demand: Weekday vs Weekend** analysis and the **Hourly Wait Time by Day of Week** heatmap.

---

## Ward Filter

Some source records do not contain usable ward-level detail and are labelled **Not included elsewhere**.

I created `Ward Filter` so those records could be excluded from ward-level comparisons without removing them from the overall trip analysis.

```DAX
Ward Filter =
IF(
    Trips_Q2_2026[pickup_ward] = "Not included elsewhere",
    "Exclude",
    "Include"
)
```

This column was used when comparing trip volume and passenger wait time across individual Toronto wards.
